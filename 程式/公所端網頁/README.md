# 天相星 公所端網頁

直接用瀏覽器打開就能用，不需要安裝或架伺服器：

- `index.html`：公所工作台
- `field.html`：現勘公務手機
- `farmer.html`：農民端（手機版面；上方可切換測試帳號）

頂列「資料」可切換兩種模式：

- **測試資料庫**（預設）：一場虛構颱風、94 件案件、14 筆災前基準、抽查與評等數字。人名、地號、圖資都是假的，圖資用色塊表示。分級一律由規則即時計算，不是寫死的。內容在 `js/testdb.js`。
- **留白（未接入）**：所有數據顯示「—」。

兩種模式下，送出的操作都先存進這台電腦的「本機暫存區」（左下角可查看、清空）。

```

js/app.js           版面與路由

js/vendor/qrcode.js QR 碼產生（Kazuhiko Arase，MIT 授權），離線可用
```

## 接資料

1. 在 `js/api.js` 把各函式改成呼叫後端，回傳格式寫在每個函式上方的註解。
2. 把 `CONNECTED` 改成 `true`，畫面上的「未接入」提示就會消失。
3. 分級、處理方式、下界等由 `rules.js` 依構想書規則計算；後端若已算好會直接沿用。

## 構想書沒有寫明、這裡先自行決定的地方

- 災前基準「三種確認方式」：暫訂為「依套疊結果確認」「修正範圍後確認」「排定到場確認」（`config.js` 的 `baselineConfirmMethods`）。
- C 缺失的處理（2026-10-25 定案）：一律先要求補件；補件回來重新檢核；期限過了未補件，依公所實際量能處理。影像類（雲遮、像素不足、樹冠遮蔽或網室）在有無人機量能時計算航線、提交飛行申請、派飛；超出無人機量能者與非影像類排入到場，到場依 B 邊緣、抽查、申訴、C 缺失、乙丙等依現行勘查的順序，超出現勘量能者排隊。原因碼屬於哪一類在 `config.js` 的 `reasonRoute`，量能預設值在 `capacity`。
- 不予救助的法定原因清單由接口提供，未接入時無法送出不予救助。
- 工作日未扣國定假日。
